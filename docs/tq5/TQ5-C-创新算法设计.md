# TQ5-C · 创新功能算法设计(参考同花顺决策先锋, 全部用通达信数据实现)

> 每个指标按: 输入数据 → 公式 → 阈值(入 config) → 输出信号 → 数据源 给出设计。
> 实现优先级建议: P1 牛熊线 → P2 机构活跃度 → P3 GS策略 → P4 三指标共振 → P5 分时突破。
> 共同原则: 阈值全部进 config; 证据链结构化输出(对齐 MI1 证据链风格); 不编造口径。

## 1. 牛熊线(P1, 最简, K线可算)
- **输入**: TQ get_market_data 日K(≥60日)
- **公式**: 牛线 = 20 日加权均线(WMA, 收盘*权重按近大远小); 马线 = MA5; 买卖线 = 马线
- **信号**: 牛线上穿马线(金叉) → G(买入); 下穿(死叉) → S(卖出)
- **输出**: 三线数值 + G/S 事件 + 当前状态(多头/空头排列)
- **数据源**: TQ K线(已接入)

## 2. AI机构活跃度(P2, K线可算, 无需 L2)
- **输入**: 日K(开/高/低/收/量) × N 日
- **公式**(6 分量各自标准化到同量纲后取 MAX, ×1.2 灵敏度系数):
  1. 影线分量 = max(上影线,下影线)/实体 或 /收盘
  2. 涨幅分量 = |当日涨幅|/3%
  3. 高开分量 = |开盘-昨收|/昨收 /1%
  4. 量比分量 = 当日量/5日均量
  5. 振幅分量 = (高-低)/昨收 /5%
  6. 位置跃迁分量 = |收盘-N日中位|/收盘 /3%
  活跃度 = MAX(6分量) × 1.2
- **阈值**: >1.56 生命线(紫·非常活跃) / >3 强势线(红·比较活跃) / ≤1.56 绿·不活跃
- **辅助**: 连强天数(活跃度>1.56 连续日数)、五日均值
- **输出**: 当日活跃度值 + 分档 + 连强天/五均
- **数据源**: TQ K线(已接入); 待实测样本标定后微调分量权重(权重入 config)

## 3. GS 策略主图(P3)
- **输入**: 日K(≥120日) + 成交量
- **公式**:
  - 趋势系统: MA5/MA10/MA20 多头排列(短>中>长且上翘)=中期多; 反之空
  - 量价背离: 顶背离=价创新高而量能峰值递降(取 20 日窗口内极值对); 底背离反之
  - 波段高低点: 分形识别(左右各 K 根确认, K=config 默认 3)自动标注顶/底
  - 拐点概率: 统计历史上"当前特征组合(排列+背离+分位)"出现后 5 日内反转的频率(样本外推, 概率=命中/总数)
- **输出**: G 信号(底部拐点+底背离+多头萌芽)、S 信号(顶部拐点+顶背离)、G 区(紫柱)/S 区(绿柱)/横盘区
- **数据源**: TQ K线; 拐点概率需本地历史库(可用 TQ 批量 K 线自建)

## 4. 暗盘资金(已落地 TQ4, 本文档只做展示层对齐)
- **输入**: .tck 逐笔(order_cluster) + 申报/撤单事件
- **路径 B(精确版, 已实现)**: 逐笔成交金额切档四档净额 + 方向("2B"/"2S"); 委托号显式关联研究中
- **路径 A(近似版, 补充实现, 无逐笔场景)**: 按日K形态把成交量分摊: 阳线=买量=量×(收-低)/(高-低), 卖量=量-买量; 阴线对称(配置可选)
- **四种价量组合(展示层)**: 涨+红柱=健康持股 / 跌+绿柱=出逃回避 / 跌+红柱=吸筹反转 / 涨+绿柱=诱多警惕(红绿柱=净额符号连续序列)
- **数据源**: .tck 落盘(盘后) / TQ 快照(盘中近似)

## 5. 分时突破(P5, 盘中实时)
- **"突"信号**: 条件=①盘中横盘≥15 分钟(日内高低点带宽/开盘价 < X1% 且无创新高) ②当前 3 秒量>前 20 均值×Y 倍 ③价格突破日内前高 ④darkflow 超大+大单净额为正且持续 → "突"
- **"积"信号**: 开盘后 Z 分钟内, 超大+大单累计净买>0 且价格未大涨(蓄势) → "积"
- **数据源**: TQ get_market_snapshot 轮询(3s) + .img 十档(盘后复盘) + darkflow(当日盘后校验)
- **阈值**: X1/Y/Z 全部入 config

## 6. 趋势操盘线(P3.5)
- **输入**: 日K
- **公式**: 三线 EMA 体系: 红线=EMA(close, N1)/黄线=EMA(close, N2)/绿线=EMA(低点, N3); 红上黄=多方带
- **信号**: 上升趋势中回落至多方带内收阳 → 买点; 下降趋势反弹至绿线无力(收盘不破+上影) → 卖点
- **数据源**: TQ K线; N1/N2/N3 入 config

## 7. 三指标共振(核心实战逻辑, 依赖 1-4)
- **买入共振** = GS 出 G + 暗盘连续红柱(净额>0 连续 D 日) + 机构活跃度 ≥3
- **卖出共振** = GS 出 S + 暗盘连续绿柱 + 活跃度快速回落(今日 < 五日均×0.7)
- **选股流程** = 暗盘净流入 + 活跃度>6(>12 更佳) + GS 处 G 区出 G + 自选池/条件过滤(问财为 THS 能力, TDX 侧用 tdx_screener **可接入** 或自选池)
- **输出**: 共振事件 + 三指标各自状态 + 证据链(全结构化, 对齐 MI1)
- **数据源**: 1-4 的输出汇总

## 与 MI1 的关系
- MI1 七口诀=当日意图快照; 本文档三指标体系=趋势/资金/活跃度共振。两者共用 darkflow 分档与 TQ 数据层, 证据链格式统一, 不重复造轮子。
