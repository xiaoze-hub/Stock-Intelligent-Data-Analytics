# MI1 · 当日主力意图资金（TQ 版）

对 002361.SZ 及自选池输出【当日主力意图】5 档评级 + 结构化证据链。
数据源: 本机通达信 TQ 网关(JSON-RPC, 默认 http://127.0.0.1:17709/)。

## 文件
| 文件 | 作用 |
|------|------|
| tq_main_force.py | 数据层: 快照/扩展指标/撤单/K线/SC03 → 标准化 DataFrame |
| tq_intent.py | 规则层: 七口诀代码化(位置优先+量价) + 托盘出货检测 + 5 档评级 |
| run_intent.py | CLI: 跑自选池, 输出 CSV + JSON(证据链) |
| mi1_config.json | 全部阈值参数(网关地址/自选池/七口诀阈值), 禁止改代码硬编码 |

## 运行
```bash
pip install pandas            # 唯一第三方依赖
python run_intent.py          # 用配置里的 watch_pool
python run_intent.py --codes 002361.SZ,603737.SH --output ./out
```
输出 `main_force_<日期>.csv`(标准化数据) + `main_force_<日期>.json`(评级+证据链)。

## 评级(5 档)
| 分 | 含义 | 触发口诀 |
|----|------|----------|
| 5 | 强多·真金进攻 | 外盘大+涨+放量 |
| 4 | 偏多·压盘吸筹 | 内盘大+涨+低位 |
| 3 | 中性·观望 | 内外相当+横盘 / 内外双小 / 无命中 |
| 2 | 偏空·主力退却 | 内盘大+跌+放量 / 外盘大+跌+高位 |
| 1 | 危险·对倒/出货 | 内外双大+不动(对倒) / 超大单买+大单卖(托盘出货) |

多规则同时命中按位置优先(危险信号 > 进攻 > 撤退 > 吸筹 > 中性)取最严评级,
证据链保留全部命中(哪个规则、哪几个字段、什么值)。

## 参数(mi1_config.json → rules)
| 参数 | 默认 | 含义 |
|------|------|------|
| adv_ratio | 0.05 | 外盘占比偏离 0.5 多少算"外盘大/内盘大" |
| balance_tol | 0.08 | 内外相当的容差带 |
| flat_pct | 0.5 | 横盘判定: |涨幅%| 上限 |
| vol_ratio_active | 1.2 | "放量"的量比下限 |
| vol_ratio_big | 1.5 | "内外双大"的量比下限 |
| vol_ratio_small | 0.7 | "内外双小"的量比上限 |
| pos_high / pos_low | 0.7 / 0.3 | 60 日收盘分位的高位/低位线 |
| kline_days | 60 | 分位回看窗口 |

## 数据口径(2026-08-29 实测, 详见 TQ3/TQ4 回邮)
- 撤单量/内外盘单位为【手】; 涨幅为 %; 量比沿用 fLianB; 成交额为万元
- 分位=当前价在近 60 日收盘序列中的排名占比
- **L2AMO 分档净额(超大/大/中/小单)走 TQ4 自建分档**: .tck 逐笔还原(order_cluster.py),
  盘后落盘数据, 输出至 C:\TdxQ\darkflow\{代码}_{日期}.json; 盘中/无落盘时返回 None,
  证据链如实标"盘后补全"。formula_process_mul_zb 公式路线已废弃(接口层不在本机,
  且自建分档按委托/逐笔还原更准, 详见 TQ4 回邮)
- 托盘出货(超大买+大卖)触发门槛: 净额合计 ≥ 成交额×dump_min_pct(默认3%) 或
  连续 tuopan_confirm_samples 次同向采样(见 mi1_config.json)

## 已知边界
- 周末/盘后取到的是最近交易日收盘快照, 评级口径即"当日收盘意图"
- 单只股票接口失败不阻塞整批(跳过并 warning)
- 评级为规则引擎输出, 只提供结构化证据, 不含 LLM 综合研判
